# Quick Start Guide - Advanced T-shirt Customizer

## 🚀 Instant Setup

### **Step 1: Open the File**
```
Navigate to: E:\Projects\website_v5\website_v5\frontend\public\creative-threads\
Open: tshirt-customizer.html in your browser
```

### **Step 2: Start Designing**
1. Click "Customize" on any t-shirt
2. Upload an image or add text
3. Customize with professional tools
4. Add to cart!

---

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| **U** | Upload image |
| **Ctrl/Cmd + Z** | Undo |
| **Ctrl/Cmd + Y** | Redo |
| **Delete** | Remove selected object |
| **Ctrl/Cmd + Enter** | Add to cart |

## 🆘 Troubleshooting

### **Images not loading?**
- Check internet connection (mockups from Unsplash)
- Fallback SVG will show if image fails

### **Text not editable?**
- Double-click the text on canvas
- Or select and use controls panel

### **Undo not working?**
- Make sure you're not in an input field
- Use Ctrl/Cmd+Z or click Undo button
