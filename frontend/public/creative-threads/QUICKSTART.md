# Quick Start Guide - Creative Threads T-shirt Customizer

## 🚀 Getting Started in 3 Steps

### Step 1: Open the Application
Simply open `tshirt-customizer.html` in your web browser:

**Option A: Double-click**
- Navigate to: `E:\Projects\website_v5\website_v5\frontend\public\creative-threads\`
- Double-click `tshirt-customizer.html`

**Option B: Via Browser**
- Open your browser (Chrome, Firefox, Safari, or Edge)
- Press `Ctrl+O` (or `Cmd+O` on Mac)
- Navigate to the file and open it

**Option C: Via Local Server (Recommended)**
```bash
# If you have Python installed
cd E:\Projects\website_v5\website_v5\frontend\public\creative-threads
python -m http.server 8000

# Then open: http://localhost:8000/tshirt-customizer.html
```

### Step 2: Explore the Features

#### Browse Products
1. Scroll down to see 6 t-shirt variants
2. Each shows base price and color options
3. Click "Customize" on any product

#### Design Your T-shirt
1. **Choose Variant**: Select t-shirt style
2. **Pick Size**: S, M, L, XL, or XXL
3. **Select Color**: Click color swatches (★ = premium)
4. **Set Quantity**: Use +/- buttons

#### Add Custom Design
**Upload Image:**
- Click "Image" tab
- Drag & drop or click to upload
- Adjust scale, rotation, opacity
- Flip horizontal/vertical

**Add Text:**
- Click "Text" tab
- Type your text
- Click "Add Text to Canvas"
- Customize font, size, color, alignment

**Use Graphics:**
- Click "Graphics" tab
- Click any graphic to add to canvas

#### Canvas Controls
- **Undo/Redo**: Use buttons or press Z/Y
- **Toggle Guides**: Show/hide print area (Shift+S)
- **Drag Elements**: Click and drag to reposition

### Step 3: Add to Cart & Checkout
1. Review price breakdown (updates in real-time)
2. Click "Add to Cart"
3. View cart by clicking floating cart button (bottom-right)
4. Click "Proceed to Checkout"
5. Order confirmation appears!

## 🔧 Troubleshooting

**Issue: Images not loading**
- Solution: Ensure you're viewing via http:// (use local server)

**Issue: Can't upload images**
- Solution: Check file size (max 10MB) and format (PNG, JPG)

**Issue: Canvas not rendering**
- Solution: Use a modern browser (Chrome 90+, Firefox 88+, Safari 14+)

**Issue: Pricing not updating**
- Solution: Refresh the page and try again
