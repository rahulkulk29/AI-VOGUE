💡 Common Issues & Solutions

Issue 1: Sign In button not working
Solution: Scripts must load in correct order: Appwrite SDK → Config → Auth Handler
Issue 2: Module import errors
Solution: Use standalone auth script (auth-standalone.js) instead of module-based auth.js
Issue 3: Appwrite connection failed
Solution: Check internet connection and Appwrite project configuration
Issue 4: Invalid credentials error
Solution: Ensure you're using correct email/password for your Appwrite account
